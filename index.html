⌨️ Keyboard Shortcuts

SpacePlay / pause the preview
J K LShuttle: J plays backward (press again = faster), K stops, L plays forward (again = faster)
← →Move the playhead 1 second (hold Shift for 5 seconds)
, .Step one frame back / forward
Home / EndJump to the start / end of the video
SSplit the clip at the playhead
Q / WRipple-trim the clip under the playhead: Q cuts its start back to the playhead, W cuts its end at the playhead — later clips slide earlier
MAdd a 🚩 marker at the playhead
NTurn 🧲 snapping on / off
+ / −Zoom the timeline in / out
DeleteDelete the selected clip, item, caption or marker
Ctrl+Z / Ctrl+Shift+ZUndo / redo — every change can be undone
Ctrl+S / Ctrl+OSave project / open project

Shortcuts pause while you're typing in a box, so the letter keys never fight your captions.
